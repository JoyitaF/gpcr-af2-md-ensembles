# Changelog

## 0.1.0

First release, accompanying the bioRxiv preprint.

- Pipeline from GPCRmd files: `fetch`, `prepare`, `cartesian`, `dpca`, `states`, `bootstrap`, `summarize`.
- `torsion-audit` for torsions excluded on AF2 geometry.
- `--md-replicas public|all` run modes.
- AF2 ladder task list and Slurm scripts (ColabFold 1.6.1).
- Colab smoke test on public data.
